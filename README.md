# Esprit léger — app contre la charge mentale (dossier `charge-mentale/`)

Adresse : https://michaelbeuze.github.io/carnet-lineas/charge-mentale/
iPhone (Safari) : ouvre l'adresse, puis Partager > « Sur l'écran d'accueil ».

- **Vider** : tout écrire sans trier, puis classer chaque idée (Aujourd'hui, Plus tard, Confier, Routine, Lâcher prise).
- **Aujourd'hui** : 3 essentiels maximum, les routines du jour, et les « plus tard » qui reviennent seuls à leur date.
- **Routines** : ce qui revient (poubelles, factures…), rappelé automatiquement.
- **Partagé** : ce qui a été confié, par personne, avec un bouton « Relancer » (message prêt à envoyer).
- **Moi** : météo intérieure, respiration d'une minute, bilan de la semaine, export/import des données.

Les données restent sur le téléphone (aucun compte, aucun serveur).
